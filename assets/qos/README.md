# Holafly QoS source assets

Extracted from the supplied Figma Designs page using Figwright.

- `originals/`: all 25 unique embedded images across 26 layers, byte-for-byte originals. One P2 Slack template is repeated in Figma.
- `renders/`: 10 rendered documentation/wireframe boards and the original user-flow SVG.
- `source/`: the 10 original vector PDF board exports.
- `manifest.json`: layer ids, image hashes, sizes and source mappings.

The website includes all unique images in context, with the benchmark references and original documentation in expandable galleries. P1 and operational controls remain explorations where documented scope is unresolved. Sample values are not measured results.

Benchmark references belong to their respective product owners. No original artwork was redrawn or altered.
